# John Luis Magtoto — Portfolio

A responsive developer portfolio written in TypeScript and React, built with Vinext and Vite. Includes a custom SVG orbital illustration, project filters, accessible mobile navigation, reduced-motion support, and links to GitHub and LinkedIn.

## Development

```sh
npm install
npm run dev
```

## Production

```sh
npm run build
npm start
```

Edit project data and profile copy in `app/page.tsx`, design styles in `app/globals.css`, and SEO metadata in `app/layout.tsx`.

Profile and featured repositories are based on https://github.com/JohnLuis07. LinkedIn could not be read automatically; no employment history or qualifications were inferred. Project visuals are original decorative illustrations, not application screenshots.
